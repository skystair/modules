## 1. USB 协议基础

### 1.1 USB 传输类型

| 传输类型 | 特点 | 典型应用 | 本工程使用 |
|---------|------|---------|-----------|
| **控制传输** | 可靠、双向、有握手 | 枚举、配置 | ✅ 端点0 |
| **中断传输** | 固定周期、低延迟 | HID 设备 | ✅ 端点1 IN |
| **批量传输** | 大数据、无时间保证 | U盘、打印机 | ❌ |
| **等时传输** | 恒定速率、无重传 | 音频、视频 | ❌ |

### 1.2 USB 数据包格式

```
┌─────────────────────────────────────────────────────────────┐
│                    USB 数据包结构                            │
├─────────────────────────────────────────────────────────────┤
│  SYNC │ PID │ ADDR │ ENDP │  DATA  │ CRC5/16 │  EOP      │
│  8bit │ 4bit│ 7bit │ 4bit │ 0-1024 │ 5/16bit │ 3bit      │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 USB 事务流程

```
主机 (Host)                      设备 (Device)
    │                                │
    │  ──── SETUP/OUT Token ────→    │
    │  ──── DATA0/DATA1 ────────→    │
    │                                │
    │  ←──── ACK/NAK/STALL ──────    │
    │                                │
    │  ──── IN Token ──────────→    │
    │                                │
    │  ←──── DATA0/DATA1 ───────    │
    │  ──── ACK ────────────────→    │
```

### 2.2 关键寄存器地址

```c
// USBD_STM32F10x.h
#define USB_BASE_ADDR   0x40005C00  // USB 寄存器基地址
#define USB_PMA_ADDR    0x40006000  // Packet Memory Area 基地址

// 主要寄存器偏移
#define CNTR    REG(USB_BASE_ADDR + 0x40)   // 控制寄存器
#define ISTR    REG(USB_BASE_ADDR + 0x44)   // 中断状态寄存器
#define FNR     REG(USB_BASE_ADDR + 0x48)   // 帧号寄存器
#define DADDR   REG(USB_BASE_ADDR + 0x4C)   // 设备地址寄存器
#define BTABLE  REG(USB_BASE_ADDR + 0x50)   // 缓冲区表地址
#define BCDR    REG(USB_BASE_ADDR + 0x58)   // 电池充电检测/D+上拉

// 端点寄存器 (每个端点4字节)
#define EPxREG(x)  REG(USB_BASE_ADDR + 4*(x))
```

## 3. 枚举过程详解

### 3.1 枚举流程总览

```
┌─────────────────────────────────────────────────────────────────────┐
│                         USB 枚举过程                                │
└─────────────────────────────────────────────────────────────────────┘

1. 设备插入
   ┌──────────┐                    ┌──────────┐
   │  设备    │ ── D+上拉 ────────→│  主机    │
   └──────────┘                    └──────────┘
                                    ↓ 检测到设备
2. 总线复位
   ┌──────────┐                    ┌──────────┐
   │  设备    │ ←── RESET 信号 ───│  主机    │
   └──────────┘                    └──────────┘
   ↓ 设备进入默认状态，地址=0

3. 获取设备描述符 (GET_DESCRIPTOR)
   ┌──────────┐                    ┌──────────┐
   │  设备    │ ←── GET_DESCRIPTOR ─│  主机    │
   │          │ ── Device Desc ──→│          │
   └──────────┘                    └──────────┘

4. 设置地址 (SET_ADDRESS)
   ┌──────────┐                    ┌──────────┐
   │  设备    │ ←── SET_ADDRESS ──│  主机    │
   │          │ ── ACK ──────────→│          │
   └──────────┘                    └──────────┘
   ↓ 设件获得新地址

5. 再次获取设备描述符 (用新地址)

6. 获取配置描述符 (GET_DESCRIPTOR Configuration)

7. 获取字符串描述符 (可选)

8. 设置配置 (SET_CONFIGURATION)
   ┌──────────┐                    ┌──────────┐
   │  设备    │ ←── SET_CONFIG ───│  主机    │
   │          │ ── ACK ──────────→│          │
   └──────────┘                    └──────────┘
   ↓ 设备进入配置状态，可以通信了

9. 获取 HID 描述符 (GET_DESCRIPTOR HID Report)
   ┌──────────┐                    ┌──────────┐
   │  设备    │ ←── GET_DESCRIPTOR ─│  主机    │
   │          │ ── HID Report ───→│          │
   └──────────┘                    └──────────┘
   ↓ 主机加载 HID 驱动
```

### 3.2 枚举阶段的控制传输

```
┌─────────────────────────────────────────────────────────────────┐
│                    控制传输三阶段                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  阶段1: 建立阶段 (Setup Stage)                                  │
│  ┌────────┐      SETUP Token       ┌────────┐                  │
│  │  主机  │ ────────────────────→  │  设备  │                  │
│  │        │      DATA0 (8字节)     │        │                  │
│  │        │ ────────────────────→  │        │                  │
│  │        │      ← ACK             │        │                  │
│  └────────┘                        └────────┘                  │
│                                                                 │
│  阶段2: 数据阶段 (Data Stage) - 可选                            │
│  ┌────────┐      IN/OUT Token      ┌────────┐                  │
│  │  主机  │ ────────────────────→  │  设备  │                  │
│  │        │      DATA1 (数据)      │        │                  │
│  │        │ ←────────────────────  │        │                  │
│  │        │      → ACK             │        │                  │
│  └────────┘                        └────────┘                  │
│                                                                 │
│  阶段3: 状态阶段 (Status Stage)                                 │
│  ┌────────┐      IN/OUT Token      ┌────────┐                  │
│  │  主机  │ ────────────────────→  │  设备  │                  │
│  │        │      ZLP (零长度包)    │        │                  │
│  │        │ ←────────────────────  │        │                  │
│  │        │      → ACK             │        │                  │
│  └────────┘                        └────────┘                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.3 Setup Packet 结构

```c
// 8 字节 Setup Packet 结构
typedef struct {
    uint8_t  bmRequestType;  // 请求类型 (方向、类型、接收者)
    uint8_t  bRequest;       // 请求代码
    uint16_t wValue;         // 值 (根据请求不同含义不同)
    uint16_t wIndex;         // 索引 (根据请求不同含义不同)
    uint16_t wLength;        // 数据长度
} SETUP_PACKET;

// bmRequestType 位域
// Bit 7: 数据方向 (0=主机→设备, 1=设备→主机)
// Bit 6-5: 类型 (0=标准, 1=类, 2=厂商)
// Bit 4-0: 接收者 (0=设备, 1=接口, 2=端点)

// 标准请求示例
GET_DESCRIPTOR     = 0x06  // 获取描述符
SET_ADDRESS        = 0x05  // 设置地址
SET_CONFIGURATION  = 0x09  // 设置配置
GET_REPORT         = 0x01  // HID: 获取报告
```

### 4.2 HID Report Descriptor 解析

```c
// 本工程的 HID Report Descriptor (50字节)
const uint8_t usbd_hid0_report_descriptor[] = {
    // ===== 全局项 =====
    0x05, 0x01,  // Usage Page (Generic Desktop)
    0x09, 0x02,  // Usage (Mouse)

    // ===== 主项: 应用集合开始 =====
    0xA1, 0x01,  // Collection (Application)
    0x09, 0x01,  //   Usage (Pointer)
    0xA1, 0x00,  //   Collection (Physical)

    // ===== 按钮定义 =====
    0x05, 0x09,  //     Usage Page (Button)
    0x19, 0x01,  //     Usage Minimum (1)
    0x29, 0x02,  //     Usage Maximum (2) ← 左键+右键
    0x15, 0x00,  //     Logical Minimum (0)
    0x25, 0x01,  //     Logical Maximum (1)
    0x95, 0x02,  //     Report Count (2)  ← 2个按钮
    0x75, 0x01,  //     Report Size (1)   ← 每个1位
    0x81, 0x02,  //     Input (Data, Variable, Absolute)

    // ===== 填充位 =====
    0x95, 0x01,  //     Report Count (1)
    0x75, 0x06,  //     Report Size (6)   ← 6位填充
    0x81, 0x01,  //     Input (Constant)

    // ===== X/Y 轴定义 =====
    0x05, 0x01,  //     Usage Page (Generic Desktop)
    0x09, 0x30,  //     Usage (X)
    0x09, 0x31,  //     Usage (Y)
    0x15, 0x81,  //     Logical Minimum (-127)
    0x25, 0x7F,  //     Logical Maximum (127)
    0x95, 0x02,  //     Report Count (2)  ← X 和 Y
    0x75, 0x08,  //     Report Size (8)   ← 每个8位
    0x81, 0x06,  //     Input (Data, Variable, Relative)

    // ===== 集合结束 =====
    0xC0,        //   End Collection
    0xC0         // End Collection
};

// 报告格式 (3字节):
// Byte 0: [bit1:右键] [bit0:左键] [bit7-2:填充]
// Byte 1: X 轴移动 (-127 ~ +127)
// Byte 2: Y 轴移动 (-127 ~ +127)
```

```
│   │                        │                        │              │
│   │  SETUP Token + DATA    │                        │              │
│   │ ─────────────────────→ │                        │              │
│   │                        │  写入 PMA              │              │

│   │                        │                        │              │
│   │  IN Token              │                        │              │
│   │ ─────────────────────→ │                        │              │

```

## 6. 中断处理机制

### 6.1 中断优先级

```
┌─────────────────────────────────────────────────────────────┐
│                    USB 中断类型                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  CNTR (控制寄存器) - 中断屏蔽位:                            │
│  ├── CTRM  (bit15) - 正确传输完成中断屏蔽                  │
│  ├── PMAOVRM (bit14) - PMA 溢出中断屏蔽                    │
│  ├── ERRM  (bit13) - 错误中断屏蔽                          │
│  ├── WKUPM (bit12) - 唤醒中断屏蔽                          │
│  ├── SUSPM (bit11) - 挂起中断屏蔽                          │
│  ├── RESETM (bit10) - 复位中断屏蔽                         │
│  ├── SOFM  (bit9) - 帧起始中断屏蔽                         │
│  └── ESOFM (bit8) - 期望帧起始中断屏蔽                     │
│                                                             │
│  ISTR (中断状态寄存器):                                     │
│  ├── CTR   (bit15) - 正确传输完成                          │
│  ├── PMAOVR (bit14) - PMA 溢出                             │
│  ├── ERR   (bit13) - 错误                                  │
│  ├── WKUP  (bit12) - 唤醒                                  │
│  ├── SUSP  (bit11) - 挂起                                  │
│  ├── RESET (bit10) - 复位                                  │
│  ├── SOF   (bit9) - 帧起始                                 │
│  ├── DIR   (bit4) - 传输方向 (0=OUT, 1=IN)                 │
```

### 6.2 USB_IRQHandler 处理流程

```c
// USBD_STM32F10x.c - 中断处理函数
void USB_IRQHandler(void) {
    uint32_t istr = ISTR;

    // ===== 1. 处理 USB 复位 =====
    if (istr & ISTR_RESET) {
        USBD_Reset();                           // 初始化端点
        SignalDeviceEvent(ARM_USBD_EVENT_RESET); // 通知上层
        ISTR = ~ISTR_RESET;                     // 清除标志
    }

    // ===== 2. 处理挂起 =====
    if (istr & ISTR_SUSP) {
        CNTR |= CNTR_SUSPM;                    // 屏蔽挂起中断
        usbd_state.active = 0;                  // 标记非活动
        SignalDeviceEvent(ARM_USBD_EVENT_SUSPEND);
        ISTR = ~ISTR_SUSP;
    }

    // ===== 3. 处理唤醒 =====
    if (istr & ISTR_WKUP) {
        usbd_state.active = 1;                  // 标记活动
        CNTR &= ~CNTR_SUSPM;                   // 取消挂起屏蔽
        SignalDeviceEvent(ARM_USBD_EVENT_RESUME);
        ISTR = ~ISTR_WKUP;
    }

    // ===== 4. 处理正确传输完成 (CTR) =====
    if (istr & ISTR_CTR) {
        uint32_t ep_num = istr & ISTR_EP_ID;
        uint32_t val = EPxREG(ep_num);

        // ----- RX 完成 -----
        if (val & EP_CTR_RX) {
            EPxREG(ep_num) = val & ~EP_CTR_RX & EP_MASK; // 清标志

            if (val & EP_SETUP) {
                // Setup 包处理
                ReadSetupPacket(setup_packet);   // 从PMA读取
                setup_received = 1;
                SignalEndpointEvent(ep_num, ARM_USBD_EVENT_SETUP);
            } else {
                // OUT 包处理
                USBD_EP_HW_Read(ep_num);         // 从PMA读取数据
                if (ep[ep_num].num == 0) {
                    ep[ep_num].active = 0;
                    SignalEndpointEvent(ep_num, ARM_USBD_EVENT_OUT);
                }
            }
        }

        // ----- TX 完成 -----
        if (val & EP_CTR_TX) {
            EPxREG(ep_num) = val & ~EP_CTR_TX & EP_MASK; // 清标志
            ep[ep_num].num_transferred_total += ep[ep_num].num_transferring;

            if (ep[ep_num].num == 0) {
                // 全部发送完成
                ep[ep_num].active = 0;
                SignalEndpointEvent(ep_num | 0x80, ARM_USBD_EVENT_IN);
            } else {
                // 还有数据，继续发送
                USBD_EP_HW_Write(ep_num | 0x80);
            }
        }
    }
}
```

### 7.1 PMA 读写特点

```
┌─────────────────────────────────────────────────────────────────────┐
│                    PMA 访问特性                                      │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  问题: PMA 与主内存不连续，且是 16 位宽度                           │
│                                                                     │
│  主内存 (SRAM):     PMA (USB专用):                                  │
│  ┌──────────┐       ┌──────────┐                                   │
│  │ 32位字   │       │ 16位字   │                                   │
│  │ [7:0]    │       │ [7:0]    │ ← 实际数据                        │
│  │ [15:8]   │       │ [15:8]   │ ← 填充/未使用                     │
│  │ [23:16]  │       ├──────────┤                                   │
│  │ [31:24]  │       │ [7:0]    │ ← 下一个数据                      │
│  └──────────┘       │ [15:8]   │ ← 填充/未使用                     │
│                     └──────────┘                                   │
│                                                                     │
│  解决方案: 使用 32 位指针访问，每次读取 2 个字节                    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 7.2 PMA 读写代码

```c
// 从 PMA 读取数据 (以 Setup Packet 为例)
static void ReadSetupPacket(uint8_t *setup) {
    volatile uint32_t *ptr_src;
    uint16_t *ptr_dest = (uint16_t *)setup;

    // 计算 PMA 地址 (需要 ×2 因为 PMA 是 16 位对齐)
    ptr_src = (uint32_t *)(USB_PMA_ADDR + 2*((pBUF_DSCR)->ADDR_RX));

    // 读取 4 个 32 位字 = 8 字节 Setup Packet
    for (int i = 0; i < 4; i++) {
        *ptr_dest++ = *ptr_src++;  // 每次读 32 位，但只用低 16 位
    }
}

// 向 PMA 写入数据 (以 HID 报告为例)
static void USBD_EP_HW_Write(uint8_t ep_addr) {
    volatile uint32_t *ptr_dest;
    volatile uint16_t *ptr_src;
    uint32_t num, i;

    ptr_ep = &ep[EP_ID(ep_addr)];
    num = ptr_ep->num;

    // 目标: PMA 中的 EP TX 缓冲区
    ptr_dest = (uint32_t *)(USB_PMA_ADDR + 2*((pBUF_DSCR + ep_num)->ADDR_TX));

    // 源: 应用数据缓冲区
    ptr_src = (uint16_t *)(ptr_ep->data + ptr_ep->num_transferred_total);

    // 复制数据 (每次 16 位 → 32 位对齐写入)
    i = (num + 1) >> 1;  // 向上取整到 16 位边界
    while (i != 0) {
        *ptr_dest++ = *ptr_src++;
        i--;
    }

    // 设置发送字节数
    (pBUF_DSCR + ep_num)->COUNT_TX = num;
}
```

### 7.3 缓冲区描述符初始化

```c
// USBD_Reset() 中的初始化
static void USBD_Reset(void) {
    // 设置缓冲区表地址
    BTABLE = 0;

    // EP0 TX: 地址 0x40, 大小 8 字节
    pBUF_DSCR->ADDR_TX = 0x40;
    pBUF_DSCR->COUNT_TX = 0;

    // EP0 RX: 地址 0x80, 大小 8 字节 (64字节缓冲区)
    pBUF_DSCR->ADDR_RX = 0x80;
    pBUF_DSCR->COUNT_RX = 0x8000 | (64 << 10);  // BL_SIZE=1, NUM_BLOCK=16

    // EP1 TX (HID IN): 地址 0xC0
    (pBUF_DSCR + 1)->ADDR_TX = 0xC0;
    (pBUF_DSCR + 1)->COUNT_TX = 0;

    // 配置端点寄存器
    EPxREG(0) = EP_CONTROL | EP_TX_VALID;  // EP0: 控制端点
    EPxREG(1) = EP_INTERRUPT;              // EP1: 中断端点
}
```

```c
// 1. 应用层 - 构造报告
void USB_HID_Mouse_Func(unsigned char btn_left, unsigned char btn_right) {
    uint8_t report[3];

    if (!USBD_Configured(0)) return;  // 未配置则返回

    report[0] = (btn_left ? 1 : 0) | (btn_right ? 2 : 0);
    report[1] = 0;  // X = 0
    report[2] = 0;  // Y = 0

    if (report[0] != last_buttons) {
        USBD_HID_GetReportTrigger(0, 0, report, 3);  // 发送
        last_buttons = report[0];
    }
}

// 2. Middleware 层 - 封装 HID 类请求
int32_t USBD_HID_GetReportTrigger(uint8_t instance, uint8_t rid,
                                   const uint8_t *buf, int32_t len) {
    // 检查参数
    if (instance != 0 || rid != 0) return ARM_DRIVER_ERROR;

    // 调用驱动层发送
    return usbd_driver->EndpointWrite(1 | ARM_USB_ENDPOINT_DIRECTION_MASK,
                                       (uint8_t *)buf, len);
}

// 3. 驱动层 - 写入端点
static int32_t USBD_EndpointWrite(uint8_t ep_addr, const uint8_t *data, uint32_t num) {
    volatile ENDPOINT_t *ptr_ep = &ep[EP_ID(ep_addr)];

    if (ptr_ep->active) return ARM_DRIVER_ERROR_BUSY;

    ptr_ep->data   = (uint8_t *)data;
    ptr_ep->num    = num;
    ptr_ep->active = true;

    USBD_EP_HW_Write(ep_addr);  // 写入 PMA

    return ARM_DRIVER_OK;
}
```

```
  │  ↓
  │  枚举完成，设备进入配置状态
  │  ↓
  │  主机加载 HID 驱动，开始轮询 EP1 IN
  │

设备 (Device):
  │
  │  D+ 上拉使能 (BCDR_DPPU)
  │  ↓
  │  USB_IRQHandler() - RESET
  │    └── USBD_Reset() 初始化端点
  │  ↓
  │  USB_IRQHandler() - SETUP (GET_DESCRIPTOR)
  │    └── 读取 Setup Packet
  │    └── SignalEndpointEvent(SETUP)
  │    └── Middleware 准备设备描述符
  │  ↓
  │  USB_IRQHandler() - IN (发送描述符)
  │    └── 数据从 PMA 发送到主机
  │    └── SignalEndpointEvent(IN)
  │  ↓
  │  ... 重复处理各种请求 ...
  │  ↓
  │  SET_CONFIGURATION 完成
  │    └── USBD_Configured() 返回 true
  │  ↓
  │  等待按键事件，准备发送 HID 报告
```

### 10.2 HID 报告发送时序

```
时间轴 ──────────────────────────────────────────────────────────────→

用户操作:
  │
  │  按下 PC13 (左键)
  │  ↓

任务调度 (1ms 周期):
  │
  │  ┌─────────────────────────────────────────────────────────────┐
  │  │ task_mode 第 N 次循环                                       │
  │  │   Board_func(): GPIO 读取 → Board_REG_in[0] = 1            │
  │  │   key_func(): 消抖 → keystr[0].press = 1 (第50ms确认)       │
  │  │   modefunc_func():                                          │
  │  │     modefunc_Lastfunc():                                    │
  │  │       left = keyXvalread(0, PRESS) = 1                      │
  │  │       right = keyXvalread(1, PRESS) = 0                     │
  │  │       USB_HID_Mouse_Func(1, 0)                              │
  │  │         report = {0x01, 0x00, 0x00}                         │
  │  │         report[0] != last_buttons → 发送                    │
  │  │         USBD_HID_GetReportTrigger(0, 0, report, 3)          │
  │  └─────────────────────────────────────────────────────────────┘
  │  ↓

USB 驱动:
  │
  │  ┌─────────────────────────────────────────────────────────────┐
  │  │ USBD_EndpointWrite(0x81, report, 3)                         │
  │  │   └── USBD_EP_HW_Write(0x81)                                │
  │  │         ├── ptr_dest = PMA + EP1_TX_ADDR                    │
  │  │         ├── *ptr_dest = 0x0001  (report[0] + report[1])     │
  │  │         ├── COUNT_TX = 3                                    │
  │  │         └── EPxREG(1) |= EP_TX_VALID                       │
  │  └─────────────────────────────────────────────────────────────┘
  │  ↓

USB 总线:
  │
  │  ┌─────────────────────────────────────────────────────────────┐
  │  │ 主机每 16ms 发送 IN Token (EP1)                             │
  │  │   ↓                                                         │
  │  │ 设备检测到 EP1 TX 状态为 VALID                              │
  │  │   ↓                                                         │
  │  │ 设备发送 DATA1 (3字节): 01 00 00                            │
  │  │   ↓                                                         │
  │  │ 主机接收数据，发送 ACK                                      │
  │  │   ↓                                                         │
  │  │ 设备收到 ACK，产生 CTR_TX 中断                              │
  │  └─────────────────────────────────────────────────────────────┘
  │  ↓

中断处理:
  │
  │  ┌─────────────────────────────────────────────────────────────┐
  │  │ USB_IRQHandler()                                            │
  │  │   ├── EP_CTR_TX 标志置位                                    │
  │  │   ├── 清除 CTR_TX 标志                                      │
  │  │   ├── num_transferred_total += num_transferring              │
  │  │   ├── num == 0 → 发送完成                                   │
  │  │   ├── active = 0                                            │
  │  │   └── SignalEndpointEvent(EP1_IN, ARM_USBD_EVENT_IN)        │
  │  └─────────────────────────────────────────────────────────────┘
  │  ↓

主机处理:
  │
  │  ┌─────────────────────────────────────────────────────────────┐
  │  │ Windows HID 驱动接收报告                                    │
  │  │   ├── 解析 Byte 0: bit0=1 → 左键按下                       │
  │  │   ├── 生成鼠标左键按下事件                                  │
  │  │   └── 系统响应: 显示点击效果                                │
  │  └─────────────────────────────────────────────────────────────┘
```

## 附录 A: 关键寄存器位域

### CNTR (控制寄存器)

```
Bit 15: CTRM   - Correct Transfer Interrupt Mask
Bit 14: PMAOVRM - PMA Over/underrun Interrupt Mask
Bit 13: ERRM   - Error Interrupt Mask
Bit 12: WKUPM  - Wake-up Interrupt Mask
Bit 11: SUSPM  - Suspend Mode Interrupt Mask
Bit 10: RESETM - USB Reset Interrupt Mask
Bit 9:  SOFM   - Start of Frame Interrupt Mask
Bit 8:  ESOFM  - Expected Start of Frame Interrupt Mask
Bit 4:  RESUME - Resume Request
Bit 3:  FSUSP  - Force Suspend
Bit 2:  LPMODE - Low-power Mode
Bit 1:  PDWN   - Power Down
Bit 0:  FRES   - Force USB Reset
```

### ISTR (中断状态寄存器)

```
Bit 15: CTR    - Correct Transfer
Bit 14: PMAOVR - PMA Over/underrun
Bit 13: ERR    - Error
Bit 12: WKUP   - Wake-up
Bit 11: SUSP   - Suspend Mode
Bit 10: RESET  - USB Reset
Bit 9:  SOF    - Start of Frame
Bit 8:  ESOF   - Expected Start of Frame
Bit 4:  DIR    - Direction of Transaction (0=OUT, 1=IN)
Bit 3:0 EP_ID  - Endpoint Identifier
```

### EPxREG (端点寄存器)

```
Bit 15: CTR_RX   - Correct RX Transfer
Bit 14: DTOG_RX  - Data Toggle RX
Bit 13:12 STAT_RX - RX Status (00=DISABLED, 01=STALL, 10=NAK, 11=VALID)
Bit 11: SETUP    - Setup Transaction Completed
Bit 10:9 EP_TYPE - Endpoint Type (00=BULK, 01=CONTROL, 10=ISO, 11=INTERRUPT)
Bit 8:  EP_KIND  - Endpoint Kind
Bit 7:  CTR_TX   - Correct TX Transfer
Bit 6:  DTOG_TX  - Data Toggle TX
Bit 5:4 STAT_TX  - TX Status (00=DISABLED, 01=STALL, 10=NAK, 11=VALID)
Bit 3:0 EA       - Endpoint Address
```

### BCDR (电池充电检测寄存器)

```
Bit 15: DPPU   - DP Pull-Up Enable (用于软件连接/断开)
Bit 1:  PS2DET - USB Port Power Switching (主机/设备检测)
```

## 附录 C: 常见问题排查

| 现象 | 可能原因 | 排查方法 |
|------|---------|---------|
| 设备无法枚举 | D+ 上拉未使能 | 检查 BCDR_DPPU 位 |
| 设备无法枚举 | 描述符错误 | 使用 USB 分析仪抓包 |
| 枚举后无法通信 | 端点未正确配置 | 检查 EPxREG 设置 |
| 数据发送失败 | PMA 地址计算错误 | 检查 ADDR_TX 和缓冲区地址 |
| 数据不完整 | COUNT_TX 设置错误 | 确认发送字节数 |
| 主机无响应 | 端点状态不是 VALID | 检查 EP_STAT_TX |
| 按键无反应 | 消抖时间过长 | 调整 KEYshortTIM |
| 按键无反应 | 描述符大小不匹配 | 检查 IN_REPORT_MAX_SZ |
